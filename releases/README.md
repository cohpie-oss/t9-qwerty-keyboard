# Release archive

This folder stores installable APKs for published T9 QWERTY Keyboard versions.

Each release must be kept under a versioned filename:

`T9QwertyKeyboard-v<version>-debug.apk`

Do not replace or remove a prior version when publishing a new release. The most
recent version is listed in the repository root README and the full change
history is in [CHANGELOG.md](../CHANGELOG.md).
